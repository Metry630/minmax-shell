# Fonts

Self-hosted, both under the SIL Open Font License 1.1 (the licence texts sit beside them):

| File | Font | Source |
|---|---|---|
| `press-start-2p.woff2` | Press Start 2P (CodeMan38), latin subset | fontsource / google/fonts `ofl/pressstart2p` |
| `departure-mono.woff2` | Departure Mono 1.500 (Helena Zhang) | github.com/rektdeckard/departure-mono, release v1.500 |

Display text (titles, splashes, big numbers) uses Press Start 2P; HUD labels use Departure Mono;
paragraphs stay in the system sans (docs/DESIGN.md).
